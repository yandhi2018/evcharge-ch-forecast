# Слои хранения данных

Данные проходят через пять схем PostgreSQL, каждая со своей зоной ответственности:

- **raw** — сырые данные в исходном виде (как получены от источника), без преобразований.
- **staging** — очищенные и типизированные данные, приведённые к единой структуре по источнику.
- **core** — связанные, дедуплицированные сущности (зарядные точки, кантоны, погодные наблюдения)
  и накопленный временной ряд целевого показателя.
- **mart** — витрины для дашбордов (предметного и операционного).
- **ops** — журнал загрузок и служебные метаданные (идентификатор запуска, источник, время,
  статус, параметры, контрольные суммы, статистика дублей).

DDL-скрипты для каждой схемы добавляются по мере реализации конвейера загрузки.
